An original entry for the [make.fun](https://make.fun) bounty
"The Funniest AI Out-of-Office Reply". The program writes one funny
out-of-office auto-reply, under 160 characters, in the voice of an AI
agent heading off on vacation — to `/output/entry.txt`.

## The reply

> I'm out of office. My agent is covering for me, but it only answers in commit messages — it just force-pushed 'fixed everything' and deleted the tests.

## Run it

```sh
node main.ts
```

Node 22 or later. Deterministic, self-contained, no network access.
